# WeUI + 微信小程序设计规范

本文档描述基于 WeUI 设计体系与微信小程序设计指南的样式规范，适用于使用 `weui-design-vue` 组件库的第三方 uni-app 项目。

## 适用范围

本文档包含两部分内容，注意区分：

- **weui-design-vue 组件库样式规范**（第一~四章、第六~七章）：组件自带样式遵循的色彩、排版、间距、圆角约定，以及样式自定义方法。这些约定与 `weui` CSS 变量一一对应，可直接通过 extClass 或主题变量覆盖。
- **微信小程序平台通用规范**（第五章）：设计稿基准、导航栏、TabBar、可点区域等微信平台设计指南，属于平台通用规则，与组件库无关，仅在小程序端开发时参考（H5 端无需遵循）。

---

## 一、色彩体系

### 1.1 品牌色

| 用途 | 色值 | CSS 变量 | 说明 |
|------|------|----------|------|
| 品牌绿 | `#07C160` | `--weui-BRAND` | 主操作、链接、选中态 |
| 品牌绿浅 | `#06AE56` | `--weui-LINK` | 链接色（hover/active） |

**使用**：主操作按钮、文字链接、开关、选中态统一用品牌绿。

---

### 1.2 功能色

| 语义 | 色值 | CSS 变量 | 使用场景 |
|------|------|----------|---------|
| 红色/危险 | `#FA5151` | `--weui-RED` | 删除、错误、警告 |
| 橙色/警示 | `#FFC300` | `--weui-ORANGE` | 待处理、提醒 |
| 绿色/成功 | `#91D300` / `#07C160` | `--weui-GREEN` | 成功、已完成 |
| 蓝色/信息 | `#10AEFF` | `--weui-BLUE` | 链接、信息 |
| 紫色/特色 | `#6467F0` | `--weui-PURPLE` | 特殊强调 |

**使用规则**：
- **红色** 仅用于明确错误/删除操作；不可用于促销、折扣标记
- **橙色** 用于需要引起注意但不危险的场景
- **绿色** 与品牌绿区分：功能成功用功能绿（`#91D300`），品牌识别用品牌绿（`#07C160`）

---

### 1.3 中性色 — 前景文字（FG）

WeUI 定义五级文字色，从深到浅：

| 级别 | 色值 | 不透明度 | CSS 变量 | 使用场景 |
|------|------|---------|----------|---------|
| FG-0 | `rgba(0,0,0,0.9)` | 90% | `--weui-FG-0` | 主要文字（标题、正文、列表项标题） |
| FG-1 | `rgba(0,0,0,0.55)` | 55% | `--weui-FG-1` | 描述文字、补充说明 |
| FG-2 | `rgba(0,0,0,0.3)` | 30% | `--weui-FG-2` | 占位文字、弱提示 |
| FG-3 | `rgba(0,0,0,0.1)` | 10% | `--weui-FG-3` | 分割线、禁用态边框 |
| FG-4 | `rgba(0,0,0,0.15)` | 15% | `--weui-FG-4` | 点击态背景 |
| FG-5 | `rgba(0,0,0,0.05)` | 5% | `--weui-FG-5` | 极浅背景 |

**使用规则**：
- **标题/正文** → FG-0（深黑）
- **辅助说明** → FG-1（中灰）
- **placeholder/弱文案** → FG-2（浅灰）
- **分割线/禁用** → FG-3
- **按下反馈** → FG-4

---

### 1.4 中性色 — 背景（BG）

| 级别 | 色值 | CSS 变量 | 使用场景 |
|------|------|----------|---------|
| BG-0 | `#EDEDED` | `--weui-BG-0` | 页面底色 |
| BG-1 | `#F7F7F7` | `--weui-BG-1` | 次级背景（半屏弹窗头部） |
| BG-2 | `#FFFFFF` | `--weui-BG-2` | 卡片/列表/弹窗主背景 |
| BG-3 | `#F7F7F7` | `--weui-BG-3` | 灰底块（表单提示区） |
| BG-4 | `#4C4C4C` | `--weui-BG-4` | 深色背景（半屏弹窗） |
| BG-5 | `#FFFFFF` | `--weui-BG-5` | 白色背景（Tab/Badge 文字） |

**使用规则**：
- 页面背景用 `#EDEDED`（BG-0），列表/卡片内部用 `#FFFFFF`（BG-2）
- 列表项、卡片使用白色背景（BG-2），与页面底色形成层次

---

### 1.5 暗色模式 (DarkMode)

WeUI 提供完整的暗色主题 Token 映射，建议在支持 DarkMode 的小程序项目中按需适配，遵循微信小程序 `@media (prefers-color-scheme: dark)` 或配置文件自动切换。

## 二、排版

### 2.1 字体族

| 平台 | 字体栈 |
|------|--------|
| 通用 | `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif` |
| 小程序 | 系统默认字体，在 WeUI CSS 中已设置 |

---

### 2.2 字号体系

| 级别 | 字号 | 行高 | CSS 变量 | 使用场景 |
|------|------|------|----------|---------|
| 大标题 | 22px | 1.4 | — | 导航栏标题 |
| 标题 | 17px | 1.4 | — | 页面标题、列表项标题 |
| 正文 | 17px | 1.4 | — | 正文段落、cell title |
| 描述 | 14px | 1.4 | — | 辅助描述 |
| 说明 | 12px | 1.4 | — | 标签、提示、时间 |
| 极小 | 10px | 1.2 | — | Badge 数字、角标 |

**使用规则**：
- 页面主文字 ≥ 14px，不得小于 12px
- 列表项标题 `17px` FG-0，描述 `14px` FG-1
- placeholder 文字 `17px` FG-2（字号与输入内容一致）
- 按钮文字 `17px`（default/medium）、`14px`（mini）、`12px`（xmini）

---

### 2.3 字重

| 字重 | 数值 | 使用场景 |
|------|------|---------|
| Regular | 400 | 正文、描述、表单标签 |
| Medium | 500 | 按钮文字、导航标题、卡片标题 |
| Bold | 700 | 极少使用（WeUI 风格克制） |

**使用规则**：
- 标题用 Medium（500），正文用 Regular（400），避免随意加粗
- WeUI 标题虽用 500 字重但不显厚重（字体渲染差异）

---

## 三、间距

### 3.1 标准间距值

| 间距 | 值 | 使用场景 |
|------|-----|---------|
| 超大 | 24px | 页面左右边距（非满屏）、区块间距 |
| 大 | 16px | 卡片内边距、列表项内左右间距 |
| 中 | 8px | 元素间间距、表单组间距 |
| 小 | 4px | 紧密元素间距 |

---

### 3.2 组件关键尺寸

| 组件/元素 | 参考高度 | 说明 |
|-----------|---------|------|
| Button（default/medium） | 48px | 标准按钮 |
| Button（mini） | 32px | 小按钮 |
| Button（xmini） | 24px | 极小按钮 |
| Cell（单行） | 56px | 标准单元格 |
| NavBar | 56px | 导航栏 |
| TabBar | 60px | 底部标签栏 |
| Picker indicator | 56px | 选择器指标行 |
| Searchbar | 44px | 搜索栏高度 |
| Switch | 32px 宽 × 20px 高 | 开关尺寸 |
| Badge（数字） | 18px（圆形直径） | 徽章 |

---

### 3.3 页面布局参考

```
┌─────────────────────────────┐  顶部
│         NavBar 56px         │
├─────────────────────────────┤
│                             │  24px 间距
│    ┌───────────────────┐    │
│ 16 │                   │ 16 │  卡片 padding 16px
│ px │    Cell Group      │ px  │
│    └───────────────────┘    │
│         8px 间距             │
│    ┌───────────────────┐    │
│ 16 │                   │ 16 │
│ px │    Cell Group      │ px  │
│    └───────────────────┘    │
│                             │
│        TabBar 60px          │  固定底部
└─────────────────────────────┘
```

**使用规则**：
- 页面左右留白 ≥ 16px（推荐 24px 或无边距满屏白底卡片）
- 连续同类 Cell 组间距 8px
- Cell 内左右间距 16px
- 表单底部提交按钮与上方间距 24px

## 四、圆角

| 圆角值 | 使用场景 |
|--------|---------|
| 2px | 进度条、指示条端点 |
| 4px | 输入框、搜索栏 |
| 8px | 按钮、Toast、Badge 中等圆角 |
| 12px | Dialog 弹窗、Actionsheet 菜单 |
| 16px | 半屏弹窗顶部 |
| 18px | 胶囊型 Badge（数字） |

**使用规则**：
- 按钮/可交互元素用 8px 圆角（柔和可点）
- 输入框用 4px 圆角（规整输入）
- 弹层/卡片用 12-16px（层次感更高）
- Badge 数字用胶囊型（18px 全圆）或正方形小圆角

**重要**：圆角值不应随意增大。WeUI 的圆角设计克制且统一，过大的圆角（如 20px+ 的按钮）会脱离 WeUI 的简洁美学。

## 五、微信小程序设计指南

### 5.1 设计稿基准

- **设计稿宽度**：750px（iPhone 6/7/8 物理分辨率）
- **逻辑像素比**：@2x（750 / 375 = 2x）
- **使用 rpx**：uni-app 中自动转换，750rpx = 屏幕宽度

---

### 5.2 导航栏规范

- **高度**：56px（含状态栏则为 88px）
- **标题**：居中，22px Medium
- **按钮**：左侧返回（≤ 2 个操作），右侧操作按钮
- **背景色**：白色 `#FFFFFF`（头图场景可用深色背景）
- **禁止**：在导航栏放置过多操作、使用陌生图标

---

### 5.3 底部标签栏规范

- **高度**：60px（含 safe-area 约为 88px）
- **数量**：2-5 个
- **图标**：24px × 24px，选中/未选中双态
- **文字**：10px，距底部 2px
- **顺序**：首页 → 次级 → ⋯ → "我的"（约定俗成）
- **禁止**：Tab 间层级跳转跨越（Tab 内独立路由栈）

---

### 5.4 页面布局

- **列表型页面**：Cell Group 列表 + Section Header
- **信息展示**：Form + Preview + 按钮
- **结果页面**：Msg 组件
- **弱网/空页面**：Msg（info/warn）+ 按钮引导

---

### 5.5 交互反馈

- **可点区域**：≥ 44px（微信可点区域规范），WeUI Cell 自然满足 56px
- **点击态**：Cell 点击态使用 FG-4（`rgba(0,0,0,0.15)`）
- **加载态**：Loading / Toast.loading / Loadmore
- **空态/错误态**：对应组件或文案提示

---

## 六、样式自定义

### 6.1 extClass 扩展

大部分组件支持 `extClass` prop，向根元素注入业务自定义 class 名。内置 modifier 通过语义 props 使用（规则见 SKILL.md「uni-app 复合组件构建约束」）：

```html
<weui-button type="primary" ext-class="my-custom-btn">提交</weui-button>
<weui-cell title="姓名" ext-class="my-cell" />
<weui-cells form />
<weui-icon type="success" msg />
```

```css
.my-custom-btn {
  border-radius: 12px;
  height: 56px;
}
.my-cell {
  background: #fafafa;
}
```

---

### 6.2 样式覆盖原则

| 做法 | 建议 | 禁止 |
|------|------|------|
| 通过 extClass 追加 | ✅ 推荐 | — |
| 全局 CSS 覆盖 `.weui-*` | ✅ 可用于主题统一修改 | — |
| 直接修改 `node_modules/weui` | — | ❌ 升级即丢失 |
| 修改 `_internal/` 目录 | — | ❌ 构建产物不应改 |
| 使用 `!important` | ⚠️ 仅覆盖第三方样式时 | ❌ 滥用破坏层级 |
| 用深层选择器穿透 | ⚠️ `:deep()` 慎用 | ❌ 依赖内部结构 |

---

### 6.3 主题变量覆盖

如需全局调整颜色，可覆盖 WeUI CSS 变量：

```css
:root {
  --weui-BRAND: #1AAD19;       /* 自定义品牌色 */
  --weui-RED: #E64340;         /* 自定义红色 */
  --weui-FG-0: rgba(0,0,0,0.95); /* 加深主文字 */
}
```

**注意**：品牌色修改后需同步更新开关、链接、选中态等所有依赖该变量的组件。

---

## 七、禁止事项

1. **不要修改 `_internal/`**：这是构建时自动复制的依赖，修改会在下次构建丢失
2. **不要为组件额外嵌套文件夹**：easycom 期望扁平目录结构 `components/weui/<name>.vue`
3. **不要混用命令式 API 和声明式组件**：弹层组件要么用声明式（v-model:visible）要么用命令式（Xxx.show()），不要同时操作
4. **不要忘记挂载 OverlayHost**：弹层组件依赖，缺失会导致命令式 API 不渲染
5. **不要在 slot 内再包裹一层 WeUI 同名组件**：easycom 层层解析可能循环
6. **不要使用非 WeUI 风格的间距/圆角**：不符合微信小程序用户预期
7. **不要在小程序导航栏使用自由布局**：微信对导航栏有规范限制
